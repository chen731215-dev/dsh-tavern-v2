# dsh-tavern v2.6.0 — 成人向提示段回来了（正文由你自己填）

## 一句话

上一个版本里被整段删除的 `tavern:nsfw` 破限段，这次**把机制和入口恢复了**；但**正文不再由插件内置**，
改成面板里一个可编辑字段 —— 你粘一次，永久生效。

## 恢复了什么

| 项 | 说明 |
|---|---|
| `tavern:nsfw` 注入段 | 按会话注入；过 `isTavernSession` + `decideInjectionScope` 两道判据，与会话隔离同一套语义（不会再出现"绑了 A 卡却在 B 会话被注入"） |
| `nsfwEnabled` 开关 | 面板「🎲 玩法 → 🔞 成人向提示段」勾选，实时写入服务端 state |
| **正文可编辑** | `state.nsfwPrompt` + 面板文本框；注入的就是这段原文，插件不加工、不截断（上限 20000 字符防误操作） |
| 体积统计 | `prompt-stats.json` 增加 `nsfw` 字段并计入 `total`；面板「📏 提示词体积」多一行"成人段" |
| 段顺序 | `order: -1`，排在 `tavern:edits`(order=0) 之前 —— 体积快照仍由 `edits` 落盘，位置没动 |

## 为什么正文放在 state 里，而不是写回代码

* 正文**不进代码、不进 npm 包**：不会随发布出门，也**不会被升级覆盖**；
* 插件本身保持"不含该段正文"—— 写什么尺度、要不要用，是使用者自己的事。

## 怎么用

1. 面板 → **🎲 玩法** → **🔞 成人向提示段**；
2. 把正文粘进文本框 → **💾 保存正文**（失焦也会自动保存）；
3. 勾选「启用」→ 下次组装提示词生效。

正文只存在本机 `<DSH_HOME>/.agent-presets/tavern-state.json` 的 `nsfwPrompt` 字段里。

## 升级影响：零

默认 `nsfwEnabled: false` + 空正文 ⇒ **一个字节都不注入**。
配置文件里若残留旧的 `nsfwEnabled: true`，只要正文为空同样不注入。
